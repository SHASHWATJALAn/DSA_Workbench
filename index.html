Time & Space Complexity Guide

Bubble Sort

Best O(n) with early exit; average/worst O(n²). In-place.

Selection Sort

Best, average and worst O(n²). Uses O(1) extra space.

Insertion Sort

Best O(n); average/worst O(n²). Useful for small or nearly sorted data.

Merge Sort

O(n log n) in all cases; typically O(n) auxiliary space.

Quick Sort

Average O(n log n), worst O(n²). Recursion stack depends on partition balance.

Linear Search

Best O(1); average/worst O(n). Works on unsorted data.

Binary Search

Best O(1); average/worst O(log n). Requires sorted data.

BFS / DFS

O(V + E) with an adjacency-list representation.

Binary Search Tree

Search/insert/delete average O(log n) in a balanced-ish tree; worst O(n) if skewed.
