# DSA Workbench — Interactive Algorithm & Data Structure Explorer

**Course:** CSC2130 — Data Structures and Algorithms  
**Project category:** Mini Project / Research / Documentation  
**Technology:** HTML5, CSS3, vanilla JavaScript

## Overview
DSA Workbench is a browser-based learning tool for exploring core data structures and algorithms. Use the three-line menu in the top-left corner to open a dedicated workspace. The interface adjusts for desktop, tablet, and mobile browser widths.

## Modules
- **Sorting Lab:** Bubble, Selection, Insertion, Merge, and Quick Sort; comparisons, movement counts, measured runtime, visual bar chart, and a compare-all table.
- **Searching:** Linear Search and Binary Search, with result and comparison count. Binary Search sorts a copy of the entered array first.
- **BST Explorer:** insert, delete, search, in-order/pre-order/post-order traversals, tree visualization, node count, and height.
- **Graph Traversal:** create an undirected graph from an edge list, visualize it, and run BFS and DFS.
- **Complexity Guide:** concise time/space complexity reference.

## Run locally
Extract the project folder and open `index.html` in a modern browser such as Chrome, Edge, Firefox, or Safari. The application has no server, account, framework, or external library dependency.

## Suggested functional checks
1. Sorting: use `42, 17, 8, 33, 25, 11, 5, 29`; run each algorithm and Compare all.
2. Searching: search for a present value and a missing value using both methods.
3. BST: load the sample, try all three traversals, then insert/search/delete a value.
4. Graph: build the sample graph and run BFS and DFS from A.
5. Validation: try blank or invalid inputs and check the displayed messages.
